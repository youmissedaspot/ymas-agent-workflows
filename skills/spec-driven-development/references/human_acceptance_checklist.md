# Human acceptance checklist

Use when the adopting repository reserves final product acceptance to a human owner. The repository defines the owner and sign-off process; agent verification remains separate.

- [ ] Identify the governing acceptance criteria and human decision owner.
- [ ] Prepare a small set of representative user actions, prerequisites, expected observations, and known limitations.
- [ ] Attach relevant automated checks, logs, API exercises, or other agent verification as evidence, labeled with what each check actually proves.
- [ ] Leave space for the human's observed result, defects or questions, and explicit acceptance decision.
- [ ] Keep unresolved acceptance work open; do not infer sign-off from green tests or an agent-run demonstration.
