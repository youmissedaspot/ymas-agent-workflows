# OPS_TASK_005 — Level 2 record naming

Status: Complete on `work/l2-document-naming`; integration pending.

Adopted the `DOCS` Level 2 category for this package's documentation governance. New numbered records use family, durable Level 2 category, three-digit family-wide ID, and specific description in that order. Categories are controlled retrieval vocabulary with one canonical token per concept; they do not restart family sequences. The shared bootstrap and bug-knowledge guidance requires adopting repositories to define their own taxonomy and keeps unresolved classification explicit.

Existing record filenames and IDs were preserved. This is a documentation-governance change; no product-specific taxonomy or skill activation behavior changed.
