explains in adult language using relevant repository evidence and cannot invent missing
behavior, resolve contested product authority or authorize implementation through an
explanation request. Existing workflows receive short integration links rather than
replacement workflows or compulsory report structures.

uncertainty; their results are evidence until accepted through the project's process.

counts. The three-failed-attempt ceiling and smallest-unit repair remain intact.

Authoritative conversational decisions belong in their existing durable repository owners;
